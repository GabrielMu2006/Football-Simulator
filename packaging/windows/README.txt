Football Simulator {{version}} — Windows x64 免安装版
==================================================

这是一个免安装（portable）版本：解压后直接运行，不需要安装 Python、Qt 或其他运行库，
也不会写入注册表、服务或系统目录。

一、如何启动
------------
1. 把 ZIP 完整解压到任意可写目录，例如 D:\Games\Football Simulator。
   ZIP 内的根目录 {{folder}} 必须整体保留。
2. 进入该目录，双击 {{exe}}。

重要：不要只把 {{exe}} 单独复制出来运行。程序依赖同目录下的 _internal 文件夹
（Python 运行时、Qt 与游戏资源）；缺少它无法启动。移动程序时请整体移动文件夹。

二、存档位置
------------
正式版存档保存在当前 Windows 用户目录：

    %APPDATA%\Football Simulator\
      saves\            每个存档一个子目录（save.sqlite3 + config.json）
      backups\          备份
      trash\            删除后的回收站（可恢复）
      current_save.txt  上次打开的存档名
      足球模拟器总配置.json  （仅在需要时生成）

- 删除或移动程序文件夹不会删除这些存档。
- 每个存档是独立目录，可以整体复制到另一台电脑的同名位置。
- 本版本只支持新存档格式；旧版（1.x）存档不会被读取，也不会被自动迁移或删除。

三、导入 / 导出存档
------------------
在程序内进入「存档」页面：

- 导出：生成一个 .fsarchive 完整存档包（zip 结构，含 save.sqlite3、config.json 与
  manifest.json 校验信息）。发给别人或备份时用这个文件。
- 导入：选择 .fsarchive 文件。程序会先校验格式、版本、规则版本与数据库校验和，
  通过后才安装。默认拒绝覆盖同名存档；损坏包、旧格式包会被明确拒绝且不影响已有存档。

Windows 与 macOS 的新格式 .fsarchive 可以互相导入（规则版本一致时）。

四、运行要求
------------
- Windows 10 / 11，64 位。
- 建议 1366×768 以上分辨率；在 1080p 的 125% / 150% 缩放下窗口会自适应屏幕可用区域，
  主区域可滚动，导航始终可达。
- 首次启动可能比之后稍慢（系统需要读取较大的资源文件）。

五、常见问题
------------
- 双击没有反应：确认 _internal 与 {{exe}} 在同一目录且都完整；不要从 ZIP 压缩包内直接运行。
- 提示“Windows 已保护你的电脑”：本版本未做代码签名，可点击“更多信息 → 仍要运行”。
- 想彻底卸载：删除程序文件夹即可；如需一并删除存档，再手动删除上面的 %APPDATA% 目录。
- 程序被移动后打不开：请确认移动的是整个文件夹，而不是单独的 EXE。
