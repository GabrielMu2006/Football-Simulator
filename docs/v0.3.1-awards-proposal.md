# Football Simulator V0.3.1：赛事奖项、评分与图标方案

本文件记录V0.3.1的确认规则和开发实现。用户计划开新存档，因此不设计旧存档迁移或旧赛事规则切换。现有正式应用及存档继续保留，不自动修改。

## 改版前基线

- 当前MVP从整届赛事符合出场门槛的真实球员中选择，不限冠亚军；评分相同时可能有多人并列。
- 本轮独立测试存档的三个赛季，Top20分别有前锋13、13、12人，中场7、7、8人，后卫和门将均为0；这是一个样本，不代表所有存档。现有评分10分封顶，年度榜单又额外考虑进球和助攻。
- 年度榜单目前使用球员赛季结束时所在球队的荣誉分，可能无法正确表达转会球员在其他球队的实际贡献。现有记录包括进球、助攻、创造机会、成功防守、扑救、零封、出场及实际球队；不凭空补充未记录的比赛细节。
- 身价公式直接使用现有评分。新显示评分必须与原身价计算输入分开，才能保持相同原始数据下的身价结果不变。

## 赛事奖项

适用赛事每届评选一名MVP，候选必须是赛事结束时仍在冠亚军球队、且曾代表该队实际出场的真实球员；联赛冠亚军取最终积分榜前两名，杯赛按该届正式结果确定冠亚军。若没有符合条件的真实球员，MVP空缺。次级联赛和升降级附加赛均不设MVP或EVP。

EVP从整届赛事所有参赛球队实际出场过的真实球员中评选，同届MVP不能同时获得EVP。依用户确定的固定数量尽量发满：

| 赛事 | MVP | EVP名额 |
| --- | ---: | ---: |
| 一级联赛 Premier Division | 1 | 8 |
| 君临杯 Reign Cup | 1 | 5 |
| 极境杯 Apex Cup | 1 | 5 |
| 凌越杯 Ascendance Cup | 1 | 4 |
| 不灭杯 Resurgence Cup | 1 | 4 |
| 命途杯 Destiny Cup | 1 | 3 |
| 永世杯 Aeon Cup | 1 | 1 |
| 次级联赛 Second Division | 无 | 无 |
| 升降级附加赛 | 无 | 无 |

真实候选不足时如实少发；即使MVP空缺，其他参赛球队若有真实球员仍可评选EVP。为尽量发满，建议实际出场即可进入EVP候选，场次少时通过可靠性折减处理，不以虚构球员填补。评分相同时使用完整精度、实际出场和已有的关键阶段表现等可证明因素决定顺序，最后以稳定球员ID消歧，新制MVP不出现多人并列。

一名球员在同届赛事先后效力多队，其整届实际表现累计，并保留逐队出场和获奖时实际球队记录，不用赛季末球队覆盖历史归属。曾代表冠亚军球队出场但结束时已离开该队的球员，不因此具备MVP资格；其仍可按实际出场情况参与EVP评选。

## 评分、身价与年度Top20

- 为前锋、中场、后卫和门将建立按位置校准的评价：在已有数据范围内，让成功防守、扑救和零封有足够权重，同时考虑样本量、比赛阶段和实际贡献。不强制规定每个位置的获奖或上榜人数。
- 新公式改变显示评分与新制奖项评分；原身价公式继续使用旧口径输入，避免新显示分数直接改变身价。历史已保存的成绩、奖项和榜单不因新公式被重算。
- 年度Top20结合全年实际表现、按赛事级别加权的MVP和EVP，以及球员实际随队取得的成绩。按用户选择，模拟起点为表现35%、个人赛事奖项55%、实际随队成绩10%；同级MVP暂按EVP的三倍计。先统一各项分值尺度，再按比例合成，避免因量纲差异导致实际权重偏离；赛事级别细分系数经多赛季模拟校准。这是本游戏的方案，不是声称复刻HLTV的未公开公式。
- 按用户后续确认，球队成绩分在每项赛事只计入赛事结束时球员所在球队，且球员必须曾代表该队在该届实际出场；赛事结束时无球队或未为当时球队出场，该赛事不计球队成绩。球队归属在赛事结束时冻结，后续转会不会改写。当前模拟实现的个人奖项赛事权重以一级联赛为1，君临杯和极境杯各0.625，凌越杯和不灭杯各0.5，命途杯0.375，永世杯0.125；同级MVP计3份、EVP计1份。个人奖项分和实际随队荣誉分各自按当季实际最高值归一化；表现分使用位置评分和出场样本折减，之后按35/55/10合成。该比例和系数是本版本初始参数，不能从少量模拟中推断长期分布。
- 通过多随机种子和多赛季模拟检查位置分布、分数封顶、不同场次和转会；排名依据保留可追溯数据，游戏内和报道不展示综合分及公式。

## 页面与报刊

- 球员荣誉栏显示累计MVP与EVP数量，并提供赛事、届次和实际效力球队明细；团队冠军和个人荣誉分别呈现。
- 赛事页面增加各届MVP榜单；新增独立的EVP页面，可按届次查看球员、位置和实际球队。未设奖与候选不足分别说明。
- 历史页面增加全游戏MVP数量榜和EVP数量榜，支持并列和查看明细；当前记录和归档不能重复计数。
- 新生成的赛事总报和Top20专题读取冻结奖项事实，可适当写入MVP、EVP及连续获奖，不虚构比赛情节。

## 新存档、保存与结算顺序

用户会新开存档，V0.3.1从该存档第一届适用赛事起采用新规则；无需迁移旧存档、重算历史赛事或处理旧赛季中途切换。此前正式版和原存档保留原状。

同一周赛事收官与年度评奖同时发生时，应先确定该周实际结束赛事的奖项，再计算适用的新年度榜单，最后和赛事档案一起可靠保存；重复读取、保存和重建投影必须幂等。赛事奖项保留球员ID、逐队出场、获奖归属及规则版本。

只在隔离数据根和测试存档副本上开发与验收，不自动修改V0.1.0、V0.2.0正式应用、用户原存档或旧配置；正式版本发布是独立步骤。

## 图标与版本

V0.3.1使用足球和盾徽为主体的简洁现代图标，去除大肥鱼形象。先提供候选预览，再制作适配不同尺寸的资源和macOS图标；开发版使用独立素材、应用标识及数据根，既有正式版图标不变。

## 验收

覆盖冠亚军限制、MVP唯一或空缺、EVP互斥与各赛事名额、候选不足、跨队出场及结束时所属球队、同分，以及同周完赛与年度结算。多赛季检验后场球员机会、评分饱和和小样本影响；用同一批原始数据对比确认原身价计算不变。检查球员、赛事、独立EVP页、历史双榜和报刊之间的数据一致，并在隔离的新测试存档中完成保存与重开测试。源码、原生候选及正式发布分别验收；本轮为源码开发与隔离测试，不构建或发布正式应用。
