# macOS 报刊功能

报刊入口已接入现行 `ui_v2_main.py` 和 macOS 应用包。每个存档单独启用；打开入口不会自动启用，也不会补写过去的报道。历史比赛、选秀及荣誉仍可作为新报道的背景材料。

## 使用

1. 在“报刊”选择“启用本存档报刊”。
2. 在“API 设置”输入 DeepSeek 密钥，可仅本次使用或保存至 macOS 钥匙串。首次从新应用包读取已有密钥，系统可能要求本人解锁授权。
3. 推进比赛后，选择已完成周次并点击“生成周报”。
4. 自动专题进入后台队列，游戏可继续推进。刊发后出现未读提示；赛事、转会、选秀和年度 Top20 页面提供相关报道入口。

密钥不进入存档、导出包、文章或日志。阅读已有文章、筛选、返回、F5 都不调用 API。

## 自动专题

- 阶段报：两级联赛半程、Reign Cup 小组赛、Apex Cup 瑞士轮、Ascendance Cup 组外循环与突围赛收官。
- 赛事总报：某届赛事完成正式结算与归档。
- 转会窗报：窗口关闭，且转会审核完成。
- 选秀报：实际选秀结果提交完成。
- Top20 专题：年度榜单结算，概览与20位球员点评分别生成，最后本地合成。

周报仍由玩家手动生成。各类专题按事件唯一标识去重，成功后不能再次生成。

## 关闭、恢复与失败

正常关闭时，等待正在进行的单次请求返回并保存，然后停止发送后续请求，不必等待整篇 Top20。自动专题下次打开相同存档继续；周报点击“继续生成”。已完成部分和原请求保留。

断网、超时、崩溃等无法确定请求结果时，任务标为未完成，不自动重复付费请求。玩家可明确重试缺失部分；原始返回和可用部分继续复用。缺少密钥或认证、余额、限流错误会暂停自动队列。

文章随 `.fsarchive` 导出、导入。已刊发文章保留原文；新 prompt 不重写旧文章或旧任务的冻结请求。

## 双版本与隔离验收

稳定 V0.1.0/V0.2.0 的 `release/macos/V0.1.0/`、`release/macos/V0.2.0/` 不随源码修改。候选使用明确的绝对可执行路径和独立 `FS_DATA_ROOT`；正常应用不需设置 `FS_PRESS_DEV=1`，设为 `0` 可显式关闭入口。Windows 暂未开放和验证本次集成。

macOS 正式入口对数据目录持有进程锁，避免两个新版本实例同时恢复同一队列。源码 QTest、Docker/Linux 检查与 macOS 包内真实交互分别记载，不能互相替代。

V0.2.0正式包使用蓝鲸足球图标，默认存档位于`~/Library/Application Support/Football Simulator V0.2.0/`，与V0.1.0分开。钥匙串沿用原服务条目，不把密钥带入发布包。
