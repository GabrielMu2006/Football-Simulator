# 周报用户 prompt / weekly-user-draft-5

为这周写一篇中文足球专栏，面向持续观察联赛的玩家。篇幅约600–1000字是参考，不必为字数凑内容；使用自然的小标题，数量随故事需要。

选出真正改变局面的比赛、球队走势或球员发挥，把有关联的事实连起来。联赛与杯赛同周发生时，可以围绕同一球队的不同命运展开，但分别写清本场比分、赛事资格和周末走势。可以关注爆冷、连续战绩及终结、老东家、晋级出局和历史突破，但不需要逐项填满，也不需要报道所有比赛。topics是选材建议，不是必写清单。

核对这些容易写错的地方：

- 榜首是否变更、领先多少分，按周初与周末的对照写，同时留意第二名是否换队；单场赛前名次是另一时点。标题里的比分、分差和球员进球数要与正文一致。
- 统计连续纪录时，使用该范围截至本周最后一场比赛的记录。同周先赢联赛再输杯赛，不能把联赛结束时的全赛事连胜当作周末仍在延续。两个范围说的是相近信息时选一个；结论不同才说明区别。
- 瑞士轮的3胜0负是资格战绩，可能含点球晋级，写“以3–0的瑞士轮战绩晋级”，不要自动写成场上三连胜；比赛胜平负另按比分写。仍在瑞士轮的球队不要写成已止步。双败首败转入败者组；两回合本场落败仍可能总比分晋级，不把这几个结果混为一谈。
- 首次、首败、纪录和历史成绩只依据明确证据，不能从一段不败推导赛季首败。

球队、赛事使用实体表中的完整英文名，球员使用给定姓名，包括标题和小标题。未知球员不需要解释“未记名”；只写已知贡献。没有奖项事实不补写MVP或奖项得主。

写成读者愿意看的报道，不在正文解释“这里不是登顶”“统计口径如何选择”等写作或校验过程。少写分钟流水账和泛泛赞美；比分及数据用来支持故事。媒体评论或球迷声音可有可无，使用规定标签，不虚构比赛信息。
