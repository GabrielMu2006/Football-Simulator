# 本地模板与历史 LLM 报道：同材料对照

## 对照范围

六类各选一篇历史测试稿，将当时的冻结材料原样交给 `local-news/4`，与保存的 LLM 成稿逐篇比较。周报是第3赛季第37周的分段生成与合刊；其余五篇是第4赛季独立测试存档中的真实 API 生成稿。每对稿件的报告 ID、材料摘要及全文见[对照目录](../../artifacts/press-revision4-20261028/comparison/manifest.json)。这是一组定性样本，不代表所有赛季的整体质量，也没有重新调用模型。

旧专题材料早于本地报刊后来增加的一些字段。因此，同材料回放能够检验相同事实如何被选用，不能据此认定新版新事件的背景数据不存在。以下区分当前表达问题与旧材料兼容问题。旧 LLM 稿本身也有已记录错误：Top20 曾将 Anthony Elanga 连续四届入选写为两届；转会稿推测了材料没有给出的年龄、细分位置和交易动机。本次逐名复核还发现阶段稿在出局名单中漏写 Northern Lords：冻结材料列出8支出局队，旧稿只写了其中7支。尽管历史报告将该稿列为“重点事实通过”，这份完整名单并未通过本次核对。这些问题不作为可借鉴事实。

## 共通问题和实现顺序建议

1. **先解决选材优先级。** 冠军、正式资格结局继续必写；有证据的争冠分差、重大逆转、卫冕者出局和决定性比赛也应得到相应篇幅。把同赛事多项结局合并，给另一条重大故事留位置。
2. **把事实连接成故事。** 以赛果、关键人物或榜单变化切入，再用必要数据说明意义；每人和每场不必用同一顺序罗列所有字段。摘要和正文首句避免原句重复。
3. **用好已有关键比赛。** 代表作不只按进球助攻数量取第一场，还应识别已完成的决赛、晋级和夺冠情境，保留实际球队、比分与可核实的进球过程。
4. **补齐旧材料兼容。** 对历史材料已存在但字段名不同、或者部分总计未提供的情况，使用已有事实并明确缺失；不从新版世界状态回填过去的报道。
5. **谨慎增加背景。** 当赛前战绩、身价、分档及历史资料充分时说明冷门依据；只有分档时明确高档出局或低档晋级，不直接称爆冷。球员旧主、选秀归属及转会后贡献仍以实际记录为准。

以上是对照后建议，除用户本轮明确提出的高档球队出局、夺冠路线球场和移除阵容人数外，不表示这些后续写作调整已经实施。
