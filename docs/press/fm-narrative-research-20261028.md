# 报刊叙事：FM 系列调研与本轮采用范围

调研及实施日期：2026-10-27—28。目标是把已经发生的赛果、人物经历和历史联系组织成报道，不改变模拟结果、排名、奖项或赛制。当前为本地模板 `local-news/3`。

## 公开资料能证明什么

| 官方资料 | 可核实内容 | 本项目的采用方式 |
| --- | --- | --- |

| [FM23 UEFA Club Competitions Licence](https://www.footballmanager.com/features/uefa-club-competitions-licence) | 抽签与对阵背景包含历史交锋、赛事最佳成绩、联赛现状及分档。 | 交锋重逢、低档出线、队史突破要有对应时点的证据，避免拿赛后排名倒推赛前强弱。 |

| [FM26 Mobile 官方功能说明](https://www.footballmanager.com/fm26/features/football-manager-26-mobile-new-features-showcase) | 移动版增加球员及媒体情境，强调存档故事随进程发展。 | 参考“经历随存档累积”的思路。Mobile与桌面版分开看；本项目没有的训练、财务、教练、情绪或采访系统不写成事实。 |

FM 官网的全站页眉目前会显示 FM27，前两篇文章的正文和原始日期仍对应 FM23。公开资料没有给出完整的内部新闻触发条件与阈值；下表中的52周、近3次交锋等条件属于本项目的明示规则，不能称为FM原算法。

## 六类文章的写法

- 周报：关键结果及其影响在前，关键人物、完整记录支持的比分转折接在同一条故事里，再择写转会或历史背景。
- 阶段报：先交代晋级、黑马、卫冕者或半程局势，再写人物与代表比赛；完整排名、分档和已经确定的对阵单列查阅。
- 赛事总报：决胜结果与冠军的意义在前，冠军整届数据作为支撑，再写正式个人奖和完整夺冠路线。
- 转会窗报：把交换双方与球员的经历放在一起。历史表现明确归到此前实际效力的球队，不把交易前数据归给新东家。
- 选秀报：本届选择先与接收球队的已结束赛季联系，旧届新秀以Top20轨迹及球队荣誉为重点；不写能力预测或尚未发生的出场。
- Top20：保持官方20人顺序及每人一段；用榜单变化、代表比赛或个人收获作为切入，再补赛季表现与球队背景。不展示综合分或公式。

## 本轮固定要求与 ABC

| 情境 | 证据与边界 |
| --- | --- |
| 卫冕冠军提前出局 | 正式淘汰状态，且未在本届决赛产生冠军时误写“提前”；双败首败进入败者组不算出局。 |
| 爆冷、黑马 | 冻结赛前的上季成绩、本季同级联赛成绩、身价等，沿用原有综合判断；分档本身不重复算作另一项证据。 |
| 几连冠、连冠终结 | 使用逐届冠军；历史缺届时不输出精确连冠数。联赛单场失利不意味着卫冕失败。 |
| 近一年新援立功 | 按52游戏周滚动；加盟必须早于相应比赛，按比赛中的真实球队归属匹配。比赛后同周办理的转会不倒用。 |
| 回归旧主、重返选秀球队 | 有实际离开/加盟记录，或真实选秀结果；未选中候选没有顺位，也不是该队选中的球员。 |
| A：首秀、首球、首个帽子戏法、百场/百球 | 首次与完整累计要求历史覆盖；区分俱乐部首秀/首球和本存档个人里程碑。 |
| B：冠军荒、上届决赛重逢、升班马首季、败者组夺冠 | 逐届冠军、实际决赛、前季及本季球队归属、杯赛正式路径。冠军荒至少隔过两个已结束的无冠赛季。 |
| C：金靴/助攻王卫冕、连续Top20终结、同季多奖 | 使用已结算正式奖项和各届完整Top20，个人随队冠军不以球队最终成绩代替。 |

## 四轮候选的最终选择

“采用”表示有证据且值得写时进入文章候选；不会为了让每一项出现而捏造剧情。用户要求只阐述现象，不展开解释赛制或判定规则。

| 编号 | 内容 | 选择 | 主要边界 |
| --- | --- | --- | --- |
| 1 | 交换搭档直接交锋 | 采用 | 同一笔交换，两人在同场分别为新队实际出场。 |
| 2 | 交易后双方的不同走向 | 采用 | 明确前后观察时段、真实场数及战绩，不归因于交易。 |
| 3 | 同分决定关键名次的原因 | 保留候选 | 本轮不新增判定规则解释。 |
| 4 | 附加赛低位突围 | 采用 | 实际联赛收官名次和最终升级结果。 |
| 5 | 单场胜负与整轮结局相反 | 采用 | 首次/次回合比分、正式总比分及晋级者分开。 |
| 6 | 瑞士轮走势逆转 | 采用 | 实际逐轮资格胜负，0–2后三连胜或2–0后三连败。 |
| 7 | 同届赛事再次交手 | 采用 | 同一赛事同届的已发生交锋，不引入之后的比赛。 |
| 8 | 同周双线反差专题 | 保留候选 | 原有必要赛果照常保留，本轮不新增这类专题触发。 |
| 9 | 同届新秀轨迹对照 | 采用 | 实际顺位与完整官方Top20，不使用“水货”等推断。 |
| 10 | 球队Top20群像 | 采用 | 按本季真实出场经历说明归属，跨队球员不冒充现队全季成员。 |
| 11 | 并列个人奖专题 | 保留候选 | 基础获奖名单仍完整呈现，本轮不新增专题触发。 |
| 12 | 个人连续进球/零封 | 采用 | 统计连续正式比赛出场，明确延续或结束；缺记录不补算。 |
| 13 | 一季为两队捧杯专题 | 保留候选 | 原有实际随队奖杯照常呈现。 |
| 14 | 一年内多次转会专题 | 保留候选 | 不新增频繁转会的原因叙述。 |
| 15 | 赛事连续不同冠军 | 采用 | 至少连续三届，逐届冠军记录完整。 |
| 16 | 队友分获射手王和助攻王专题 | 保留候选 | 不新增“包揽”式专题。 |
| 17 | 多年效力后的首次离队 | 采用 | 至少连续三个赛季的实际出场，并能证明此前没有离队记录。 |
| 18 | 同场两人戴帽专题 | 保留候选 | 两人的必要实际表现仍可按原范围写。 |
| 19 | 冠军进球贡献分布专题 | 保留候选 | 不从真实球员部分数据推断全队分布。 |
| 20 | 对同一对手连续进球、克星 | 采用 | 至少近三次实际对阵出场均进球；为该对手效力时的进球不算“对阵”。用户明确允许“克星”。 |
| 21 | 两回合持续贡献 | 采用 | 同一球员在首、次回合都真实进球或助攻，仅在第二回合完成后汇总。 |
| 22 | 不同届高顺位新秀成为队友 | 采用 | 各届真实前五顺位与截止点球队；新选中者不冒充已参加比赛。 |
| 23 | 首次击败长期未胜的对手 | 采用 | 至少三次此前交锋未胜；“首次”另须完整历史，资料不足只写有界近况。 |
| 24 | 联赛当季双杀 | 采用 | 同季同级联赛两场交锋均取胜。 |
| 25 | 多次85分钟后改写结果专题 | 保留候选 | 原有单场有证据的绝杀、绝平、逆转照常保留。 |
| 26 | 球员连续进球而球队持续未胜 | 采用 | 球员个人记录与球队同口径未胜记录都成立，保留球队纪录范围。 |
| 27 | 决赛对手后来成为队友 | 采用 | 两人在实际决赛分属两队并出场，截止点已同队，不编造私人关系。 |

## 冻结与兼容

新增背景在事件当时冻结，后续世界不回填早期周报。`local-news/1`、`local-news/2` 的完整表达保留在各自目录；已有成功稿保持原文，暂停任务续写原版本。只在本轮新建的独立测试存档中生成第三版样稿；不替换任何正式应用或用户原存档。

专题逐场工作材料继续使用现有的近三季范围，同时补充全历史的实际效力赛季摘要及决赛出场材料，分别支持长期效力后的首次离队和早年决赛对手成为队友。它们也冻结到原事件截止点，旧快照缺少这些材料时保持保守。首次及完整累计里程碑可由保留全历史证据的周报呈现，不从不完整的专题逐场材料硬算。

最终预览测试从建档起使用当前 `rules.HONOR_PROFILE`。先前未指定配置的独立样稿已标为旧配置测试基线；其旧稿继续冻结保存，不作改写。
