# V0.3.0 本地模板开发候选

本轮基线为大写 `V0.2.0`，提交 `3551b56b53a31973d3c0f867e51eeb96faedc83b`。只实现源码开发候选，不发布标签/Release，不替换两份稳定应用。

## 已确认的报道内容

- **周报**随每周推进自动后台生成，仍可立即生成或明确重试。沿用整期故事计划，通常2–4条故事；冠军和关键资格不受普通故事预算限制。包含重点赛果、积分局势、人物、纪录、冷门与卫冕出局、阶段结局；完整进球顺序支持时写逆转、末段制胜/扳平和关键进球过程，有赛前依据时写争位直接对话。无比赛周不刊发。
- **阶段报**写完整阶段排名/战绩、全部资格、已确定路线、队史突破、突出球员及代表比赛。君临杯列出实际四档与小组出线变化。半程名次不当作最终资格，次级联赛没有降级出口。
- **赛事总报**写冠军路线、决胜结果、整届数据、亚军决胜表现、正式三奖和有证据的历史意义；联赛附完整最终排名与资格。升级附加赛只写升级资格。
- **转会窗报**重点写真实交换双方的送出/得到、球员截至关窗的表现、明星及实际前五顺位新秀背景，其余已完成交易简短列出。按用户最新要求，不写窗口首尾阵容人数变化。估值不当作现金费用，不编动机。
- **选秀报**写全部实际顺位、前五重点和接收球队成绩、前两届前五新秀的实际发展；发展重点是Top20名次、球队冠军数、单季球队荣誉分，不展示能力变化。候选未选中者单列，不附顺位。球队冠军与球员实际随队冠军分开。
- **Top20**保留官方20人顺序，按位置写实际表现、代表比赛、正式个人奖项与实际随队冠军，交代首次/回归/累计/连续/排名变化，择上届靠前的至多五位落选者简评。不重新评分，不显示综合分或公式。

## 冷门、黑马与球队背景

比较赛前冻结的上季成绩、本季战绩、真实阵容总身价和抽签档位。新闻适配层保存每周开赛前快照；阶段使用该阶段第一周之前的快照，不拿收官状态倒推预期。至少两个可比维度明显处于劣势，且没有明确相反维度，才称冷门；黑马还需实际阶段多场获胜/持续晋级。君临杯档位来自已保存的参赛顺序，每四支一档，不按当前小组排名反推；档位与其来源上季排名不重复计票。

当前小型判断采用上季总顺序差至少4位、本季同级联赛已赛至少5场且名次差至少7位、身价至多对手75%作为明显差异。赛季初样本不足仍呈现已有本季战绩，但不作为强判定。没有评分器、模型或新官方排名。证据冲突时保留具体对比，不下冷门结论；旧材料缺赛前身价/战绩则省略相应判断。

球队背景使用**已结束赛季的正式球队荣誉积分**。历史累计与最近3个已结束赛季分别比较同期前四分之一，并列同等处理。历史需至少4个完整赛季才区分“传统强队”“处于低谷的传统强队”“新锐”；较短历史只描述近期表现。历史不完整不使用完整累计标签。这些是有证据的编辑措辞，不改游戏成绩、赛制或官方排名。

## 引擎与持久化

入口是 `press.local_library.LocalLibrary/LocalFeatureLibrary.generate_local()`，直接产出现有文章对象，使用结构/身份/引用检查保存；不调用 `generation_plan()` 的DeepSeek请求链，不生成模拟API包。

`engine_id=local-template`；当前模板版本 `local-news/4`。在周次/事件首次入队时固定引擎和版本；开始生成前保存带摘要的事实与故事计划，渲染不占数据库事务，最终文章原子保存。未完成本地任务重试沿用原计划和版本；成功稿、F5、重开、升级模板均不重写正文。后续模板修改应新增版本实现，并保留旧版本入口，不能移动旧任务的版本边界。

只为现有表增加可空引擎/模板列，保留周报 `(season,week)` 和计划 `report_id` 主键。NULL标记按旧DeepSeek解释。旧成功稿原样读取；旧queued/generating/paused/failed云任务保留来源和状态，本地队列不执行，也不转换。新边界的本地周报和专题共用一个调度器，专题触发边界保持原规则；不补发过去事件。

文章来源在阅读页单独标注，工程字段仅在元数据/验收资料内。生成路径不读取Credentials、不触碰钥匙串，没有云端失败回退。保留DeepSeek实现是为了旧版兼容，V0.2.0正式包继续使用其原有引擎。

## 运行与验证

使用确认的Python解释器运行：

```bash
python scripts/run_local_press_dev.py --data-root /absolute/path/to/an/isolated-v030-directory
```

启动器要求明确独立目录并设置 `FS_DATA_ROOT`；底层唯一入口仍为项目根的 `ui_v2_main.py`。不要指向稳定版存档目录。

`tests.test_press_local_templates` 覆盖语义、零网络/零钥匙串、冻结版本、去重、旧云兼容和导入导出；`tests.test_press_ui` 保留切档、后台推进、相关报道筛选、F5及重开检查，已从旧云UI测试迁为本地UI测试，不删除现行功能覆盖。Docker的core/press清单包含新本地用例，快照包含必要契约夹具。

原生Cocoa实测与Linux离屏分开记载。本轮Docker守护进程不可连接，使用独立本机数据验证；未构建.app，候选包检查明确跳过。样稿、实际测试清单、身份、源码指纹与限制见本轮 `artifacts/local-template-v030-20261027-01/ACCEPTANCE.md`。
